# Jele-ball

PRISM NOIR — тактический шутер 5v5 в браузере (Three.js + Vite), папка `shooter`.

- Карты: «Пыльный Квартал» (стиль Dust, процедурная, `shooter/src/world/DustMap.js`), «Кварцевый Карьер», «Ангар-9».
- Реалистичные модели оружия и солдат, фототекстуры и небо Poly Haven (CC0).
- Запуск: `cd shooter && npm install && npm run dev`, затем `http://localhost:5173/?dev=1&map=dust`.
- Лицензии моделей: `shooter/public/models/CREDITS.md`. Модель `soldier.glb` из примеров three.js, лицензия на публикацию не проверена.
