# PRISM NOIR — прототип тактического шутера 5×5

Раундовый командный шутер от первого лица в браузере: закладка заряда, экономика, агенты со способностями,
20 видов оружия, две карты, боты трёх уровней сложности и стрельбище. Один игрок + 4 бота против 5 ботов.
Всё (названия, оружие, агенты, карты, графика, звуки) придумано с нуля и создаётся кодом — внешних ассетов нет:
модели оружия собираются из десятков деталей (`src/weapons/GunModels.js`), карты — из боксов с процедурными текстурами, пропсами и небом (`src/world/MapBuilder.js`).
Готовые модели с бесплатных сайтов не использовались: из рабочей среды открыт только GitHub, а единственный найденный там свободный набор (Kenney Starter Kit FPS, мультяшные бластеры и стены) не подходит по стилю.

Стек: **Three.js + Vite**, чистый JavaScript (модули ES), звук через WebAudio.

## Установка и запуск

Нужен Node.js 18+.

```bash
cd shooter
npm install
npm run dev        # режим разработки → http://localhost:5173
npm run build      # сборка в папку dist/
npm run preview    # посмотреть собранную версию → http://localhost:4173
npm run check-maps # проверка карт: узлы в стенах, связность, время пути до точек
```

Собранную папку `dist/` можно открыть с любого статического сервера (пути относительные).
Играть лучше в Chrome / Edge / Firefox на отдельной видеокарте или современном ноутбуке.

| Присесть | Ctrl (запасная — Z; Ctrl+W закрывает вкладку, поэтому есть Z) |

| Перезарядка | R |

| Способности | C, Q, E; ультимейт — X |

Тряска экрана (0–150%), чувствительность, прицел (форма, цвет, размер, толщина, зазор), громкость, графика (качество, лимит FPS, FOV)
настраиваются в главном меню и в паузе.

## Правила режима

* 13 раундов до победы, на 12-м раунде стороны меняются, деньги и оружие сбрасываются.
* Фазы: закупка (18 с, из зоны спавна не выйти) → раунд (100 с) → заряд установлен (45 с до взрыва) → конец раунда.
* Победа в раунде: уничтожена команда; взрыв; обезвреживание (6 с); таймаут (защита).
  Если заряд уже стоит и погибли все атакующие, раунд продолжается — защита должна его обезвредить.
* Заряд ставит любой атакующий, стоя на точке A или B (удерживать F 3,2 с). Заряд не «носится» — это упрощение.
* Экономика: старт 800; победа +3000; поражение +1900 / 2400 / 2900 (серия поражений); установка заряда +300;
  убийство: 100–200 в зависимости от оружия. Выжившие сохраняют оружие и щит. Лёгкий щит 400 (+25), тяжёлый 1000 (+50).
* Урон зависит от части тела (голова, тело, ноги) и от дистанции; щит гасит 66% урона, пока не кончится.
  Стены пробиваются в пределах характеристики «пробитие» оружия (у снайперских — до 1,8 м).

## Агенты (5) — у каждого 3 способности и ультимейт

| Агент | Роль | Идея |
|---|---|---|
| Люмен | Разведчик | зонд и импульс подсвечивают врагов сквозь стены, ульт — вся карта |
| Мгла | Дымовой | завесы, ядовитое облако, огромная завеса |
| Вихрь | Штурмовик | вспышка, рывок, ускорение, берсерк |
| Лоза | Поддержка | лечение, щит союзникам, возрождение павшего |
| Страж | Сторож | растяжки, барьер, турель, защитный купол |

C и Q покупаются в закупке (цена и число зарядов у каждой свои), E восстанавливается сама, X копится очками
(убийство, заряд, победа в раунде).

## Веселье и «сок»

* **Танцы (V):** 6 танцев (диско, робот, волна, вихрь, флосс, прыжки) с камерой от третьего лица и битом, который синтезируется на лету.
  Победители раунда танцуют и осыпают всех конфетти, а боты иногда танцуют в фазе закупки.
* **Тряска экрана:** система «травмы» — каждое событие (выстрел, попадание по вам, взрыв, приземление) добавляет травму, из неё сглаженным шумом
  получаются качание, наклон и толчок поля зрения; при ударе по вам камера кренится в сторону стрелка. Уровень настраивается в «Графика → Тряска экрана».
* **Оружие в руках:** у каждого из 20 видов своя модель; затвор пистолета откатывается, помпа дробовика ходит, у снайперки отдёргивается рукоятка затвора,
  при перезарядке рука вынимает магазин и вставляет новый, оружие покачивается и запаздывает за поворотом мыши.

### Ключевые решения простыми словами

* **Стрельба — «луч».** Выстрел — невидимая линия из прицела; пуль, летящих по воздуху, нет. Так проще и честнее для ботов.
* **Физика своя и лёгкая.** Игрок — коробка 0,6×1,8×0,6 (приседа 1,3), стены — коробки. Двигаем по осям по очереди и выталкиваем из стен;
  маленькие ступеньки (до 0,5 м) берутся автоматически, так работают лестницы.
* **Карта — это данные.** Описывается JSON-ом только левая половина, правая зеркалится. Поэтому точки A и B одинаковы по расстояниям,
  а геометрия, миникарта и навигация ботов строятся из одного описания.
* **Боты ходят по графу точек**, рёбра соединяются автоматически, если между узлами нет стен; путь ищет A*.
  Они видят в конусе обзора (с учётом дыма и ослепления) и слышат шаги (не тихие) и выстрелы.
* **Способности — общий интерфейс.** Каждый тип — функция `(ctx) => boolean` в `abilities/types.js`;
  у агента в JSON указывается тип, цена, перезарядка и параметры.
* **Производительность.** Статичная карта — один меш и один набор линий (2 draw call), декали/частицы/гильзы — `InstancedMesh`,
  тень только от одного света (и только на среднем/высоком качестве), простые материалы, оружие рисуется отдельной сценой.

## Как добавить…

### …новое оружие
Откройте `src/data/weapons.json` и скопируйте любую запись, поменяв поля:

* `id`, `name`, `type` (`pistol` | `smg` | `shotgun` | `rifle` | `sniper` | `mg` | `melee`), `price`, `kill` (награда за убийство);
* `dmg` (урон в тело), `head` / `leg` (множители), `falloff: [от какой дальности, до какой, минимальный множитель]`;
* `rpm`, `mag`, `reserve`, `reload`, `draw`, `auto` (автоогонь), `burst` (очередь), `pellets` + `pelletSpread` (дробь);
* `spread`: `base` (стоя), `move` (в беге), `air` (в прыжке), `shot` (за выстрел), `max`, `recover`, `crouch` (множитель приседа);
* `recoil`: список `[рыскание°, подъём°]` для каждого выстрела — это и есть паттерн отдачи (после конца списка повторяется хвост);
* `pen` / `penMul` (пробитие стен, м / остаток урона), `speed` (множитель скорости бега), `ads` (зум на ПКМ), `zoom` (уровни у снайперок);
* `model`: `len`, `h`, `color` и флаги `stock`, `mag`, `scope`, `pump`, `box` — по ним рисуется модель в руках.

Оружие сразу появится в закупке, арсенале и в закупках ботов (`src/bots/BotBuy.js` — добавьте id в нужный список, если хотите, чтобы боты его брали).

### …нового агента
Добавьте запись в `src/data/agents.json`: `id`, `name`, `role`, `color`, `desc`, `ultCost` и четыре способности
(`slot`: `ab1` / `ab2` / `ab3` / `ult`, `key`, `type`, `cost`, `maxCharges`, `cd`, `recharge`, `params`).
Типы и их параметры: `zone` (дым, лечение, замедление, подсветка, урон), `dash`, `flash`, `heal`, `buff`, `reveal`, `wall`, `turret`, `revive`.
Агент появится в меню сам. Чтобы создать **новый тип способности**, добавьте в `src/abilities/types.js`:

```js
register('мой_тип', ({ m, a, p, sys }) => {
  // m — матч, a — кто применил, p — params из JSON
  return true; // false = способность не потрачена
});
```

### …новую карту
1. Создайте `src/data/maps/моя.json` по образцу `quarry.json`:
   * `size`, `mirror: true`, спавны `attackSpawns` / `defendSpawns` (полным списком);
   * `boxes`: `["тип", центрX, центрZ, ширина, глубина, высота, y0?, поверхность?]`, типы: `wall`, `crate`, `plat`, `low`, `patch` (покрытие пола);
   * `stairs`: `["направление", x, z, ширина, ступеней, подъём, глубина, y0]` — нижний край лестницы;
   * `zones` (подписи для HUD и миникарты, `{S}` заменяется на A/B), `nodes` (узлы навигации: `["id", x, z, y?, смотретьX?, смотретьZ?]`),
   * `sites`: только точка A — B получится зеркалом; указываются `plant`, `entries`, `holds`, `posts` (id узлов).
2. Зарегистрируйте файл в `src/data/maps/index.js`.
3. Запустите `npm run check-maps` — он покажет узлы в стенах, несвязные участки и время хода от спавнов до точек.
4. Отладка в браузере: `http://localhost:5173/?dev=1&map=моя` запускает матч сразу. В консоли: `__g.match.debugNav()` рисует граф навигации,
   `__g.topView()` — вид сверху.

## Отладочные параметры адреса

`?dev=1` — старт без меню и без Pointer Lock; `&map=quarry|hangar`, `&mode=range`, `&agent=lumen|mgla|vihr|loza|straz`, `&diff=0|1|2`,
`&side=atk|def`, `&auto=1` (игрока ведёт бот), `&speed=8` (ускорение времени). Так удобно гонять матчи ботов целиком.

## Известные проблемы и что улучшить

* Тяжёлые случаи навигации: боты не прыгают на платформы и не используют лестницы осознанно (только если путь по графу ведёт через ступени);
  в узких местах иногда застревают — срабатывает повторный поиск пути.
* Баланс ботов подбирался на глаз и зависит от карты (на «Ангаре-9» защита ближе к точкам и сильнее); у ботов есть упреждение, укрытия, размен, смена точки и сбор перед ретейком, но нет настоящего планирования обманных штурмов.
* Нет overtime (при 12:12 решает 25-й раунд), нет выбрасывания оружия и передачи заряда; заряд ставит любой атакующий.
* Способности бросаются мгновенно в точку прицела (без полёта предмета и отскоков); турель нельзя уничтожить; стена не уничтожается пулями.
* Хитбоксы — неповоротные коробки (голова/тело/ноги), модели персонажей простые и без анимации стрельбы.
* Нет дальнего тумана освещения/карт теней высокого качества для больших расстояний; тени одной картой.
* Звук синтезируется на лету: выстрелы и шаги различаются по типам, но это не записанные звуки; нет музыки в матче.
* Автотесты — только ручные сценарии (`?dev=1&auto=1`); юнит-тестов нет.
* Идеи: режимы (быстрая закладка, дезматч), больше карт (инструмент `check-maps` уже есть), редактор карт, сетевой режим,
  настоящие навмеши, больше агентов, косметика оружия, сохранение статистики между матчами.

## Самый простой запуск — один файл

`shooter/play.html` — вся игра в одном файле. Скачайте его и откройте двойным щелчком в Chrome/Edge/Firefox, ничего устанавливать не нужно.
Пересобрать его после правок: `npm run build:single`.
