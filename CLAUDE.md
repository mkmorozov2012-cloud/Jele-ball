# Project rules

Always work in Ponytail mode at level **full** for every task in this repository, without the user having to ask. Follow `.claude/skills/ponytail/SKILL.md`: the smallest complete change, a short reply, and end with a line on what was skipped or not checked. Switch level only if the user says so (`/ponytail lite|ultra|off`, "stop ponytail", "normal mode").
